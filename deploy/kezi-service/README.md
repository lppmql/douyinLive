# 客资服务安全部署

该目录用于替换现有 `kezi.lpp6.com` 的 Node 服务，保留原来的写入、增量拉取和统计接口。

部署前：

1. 将本目录上传到服务器 `/www/wwwroot/kezi/`。
2. 复制 `.env.example` 为 `.env`，填写数据库和两条不同的随机密钥。
3. 执行 `npm install --omit=dev`。
4. 在宝塔 Node 项目中把启动文件设为 `app.js`。
5. 服务只监听 `127.0.0.1:3001`，由 Nginx 的 HTTPS 站点反向代理。
6. 不要再开放服务器的 3001 公网端口。

调用时必须添加请求头：

```text
Authorization: Bearer 对应接口的密钥
```

- 写入 `/api/kezi` 使用 `KEZI_WRITE_TOKEN`。
- 拉取 `/api/douyinhao` 和统计 `/api/stats` 使用 `KEZI_READ_TOKEN`。
- 写入接口只返回成功状态，不回显手机号和抖音号；统计接口继续返回原有 `filters` 字段。
- 增量接口会返回手机号或抖音号任意一个存在的真实留资，并提供稳定的 `sourceId` 供主系统去重。
- 字段必须是字符串且不能超长，分页参数必须是规定范围内的整数，日期必须真实存在且起止顺序正确；服务会明确返回 `400`，不会把错误输入写成脏数据或静默截断。

部署后先验证：不带密钥访问客资接口必须返回 `401`，带正确密钥才能访问。
