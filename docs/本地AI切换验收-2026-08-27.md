## 启动方式

本机模型已经准备好，日常运行：

```bash
./start.sh standard
```

新电脑首次安装 Ollama 并启动其服务后，先运行 `./scripts/setup_ollama_model.sh`。
前端地址为 `http://localhost:9527`；健康接口为 `http://localhost:8000/health`，其中 `local_ai` 应为 `ok`。

## 测试方式与真实结果

```bash
make check
make doctor
cd backend
.venv/bin/python -m pytest -q tests/test_local_llm_client.py tests/test_knowledge_base.py tests/test_knowledge_completeness.py --no-cov
```

- 完整检查：458 项 pytest 和其余 `make check` 全部通过；SSE 修复后按风险规则只补跑受影响的 22 项测试与 Ruff。
- 浏览器：登录、首页、剪辑页面非空且无错误遮罩；“AI手动剪辑”和生成按钮可见。没有点击发布或自动生成新视频。
- 场次 #2494：本地 JSON、流式与统一复盘成功；复盘分析 2 人，耗时约 75 秒。
- 场次 #2479：500 段、45321 输入 Token 的选段耗时约 6 分 31 秒，返回 1 条方案且通过真实行号/时长校验。
- 运行时观察：模型使用 GPU、64K 上下文，长任务期间 Ollama 显示约 7.7GB 模型占用。短问题的耗时受冷启动和上下文切换影响，实测异步短回答曾用 56 秒，不能据此承诺固定速度。
- 当日 `make doctor` 无失败；当时 standard 模式跳过的外部大屏与监控组件产生 6 项预期提醒。该结果仅记录 2026-08-27 的历史状态，这些组件已于 2026-08-30 按 ADR 0047 正式退役。
