# ADR 总索引

ADR 是“架构决策记录”。大白话说，就是把当时为什么这么设计写下来，避免几周后只剩代码、没人记得原因。

本目录里的 ADR 正文只增不改，索引文件会随着新增 ADR 持续更新。旧方案被新方案取代时，新建一篇 ADR 说明取代关系，不直接删旧文档。

## 新增 ADR 时怎么做

1. 文件名使用下一个编号，例如 `0028-某个决策标题.md`。
2. 标题里写清楚模块和决策，不只写“优化”。
3. 内容至少包含背景、备选方案、最终决策、影响范围和验收方式。
4. 把新 ADR 加到本索引对应分组。
5. 同步更新根目录 `CHANGELOG.md`。
