## 新增 ADR 的条件

只有同时满足以下条件才新增 ADR：

1. 决策会长期影响多个模块或后续开发方式。
2. 存在两个以上合理方案，需要记录取舍理由。
3. 内容属于架构、安全、部署、数据契约或关键业务链路。

新增时使用下一个编号，并同步更新本索引和根目录 CHANGELOG。普通修复和页面优化不要新增 ADR。
