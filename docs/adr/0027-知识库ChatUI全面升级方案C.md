# ADR 0027 — 知识库 Chat UI 全面升级（方案 C）

**日期**: 2026-07-28  
**状态**: 已实施  
**决策者**: lppmql

---

## 背景

知识库的 Chat UI 存在以下问题：

1. **用户气泡颜色 `#95ec69`（微信绿）**与项目品牌色不协调
2. **硬编码颜色太多**，完全不支持深色模式
3. **移动端来源面板直接隐藏**（`display: none`），无替代查看方式
4. **欢迎页太简陋**，只有头像+标题+推荐问题
5. **流式输出无打字光标动效**，loading 体验单调
6. **对话不持久化**，刷新页面即丢失
7. **AI 回答是纯文本**，不支持 Markdown 格式（加粗/列表/代码块）
8. **无反馈机制**，无法优化回答质量

## 决策

采用**方案 C**（全面升级，对标 ChatGPT/DeepSeek 体验），包含：

### 后端新增
- **对话历史持久化**：新建 `conversations` + `conversation_messages` 两张表
- **6 个 API 端点**：列表/创建/详情/删除对话 + 追加消息 + 赞/踩反馈

### 前端升级
- **Markdown 渲染**：引入 `markdown-it`（约 30KB），AI 回答支持加粗/列表/代码块/引用
- **CSS 变量化**：所有硬编码颜色 → CSS 变量，自动支持深色模式
- **对话历史侧边栏**：可切换/新建/删除历史对话
- **打字光标**：流式输出末尾闪烁 `▍`
- **停止生成**：流式输出中可点击停止
- **赞/踩反馈**：每条 AI 消息底部 👍👎 按钮
- **来源迷你卡**：AI 消息底部内联显示来源预览
- **欢迎页升级**：渐变装饰 + 功能说明卡片 + 带图标的推荐问题
- **消息入场动效**：stagger fadeInUp
- **气泡品牌色**：用户气泡改为 `rgb(var(--primary-color))` 白字
- **确认清空**：NPopconfirm 包裹
- **无障碍**：全量 aria-label

### 替代方案评估

| 方案 | 优点 | 缺点 | 决策 |
|------|------|------|------|
| A：仅改样式 | 轻量，30分钟 | 不解决核心问题 | ❌ 不选 |
| B：样式+交互 | ROI 高 | 缺对话历史 | ❌ 不选 |
| **C：全面升级** | **完整体验** | **需后端配合，工作量大** | ✅ 采用 |

## 技术细节

### 数据库
- `conversations` 表：id, title, message_count, created_at, updated_at
- `conversation_messages` 表：id, conversation_id, role, content, sources(JSON), feedback, error, created_at, updated_at

### 新增依赖
- `markdown-it` v14.3.0（前端，Markdown 转 HTML）
- `@types/markdown-it` v14.1.2（开发依赖，TypeScript 类型）

### 文件变更
- **新建 7 个文件**：后端模型/Schema/迁移 + 前端侧边栏/composable/适配器
- **修改 9 个文件**：后端路由/模型注册 + 前端 API/类型/页面/面板/composable

### 向下兼容
- 所有现有功能保持完整
- SSE 流式问答接口不变
- 知识库搜索逻辑不变

## 后果

### 正面
- 用户可见的完整 Chat 体验升级
- 对话历史持久化，刷新不丢失
- 深色模式自动适配
- Markdown 让 AI 回答可读性大幅提升
- 反馈数据可用于优化提示词

### 风险
- `markdown-it` 新增依赖（已评估：30KB gzip，无安全风险）
- 数据库新增两张表（当前总表数：25 → 27）
- 移动端来源面板仍有优化空间（后续迭代）
