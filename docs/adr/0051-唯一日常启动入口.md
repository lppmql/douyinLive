# ADR 0051：唯一日常启动入口

- 状态：已接受
- 日期：2026-09-02

## 背景

项目同时允许执行 `./start.sh` 和 `make start`，虽然 Makefile 目标只是转调脚本，但会让新手误以为存在两套启动流程，也增加文档和排障时的表达成本。`setup.sh`、`scripts/doctor.sh` 和 `scripts/setup_ollama_model.sh` 分别用于首次安装、只读诊断和模型初始化，不承担日常启动职责。

## 决策

1. `./start.sh` 是项目唯一的日常启动入口，继续支持 `standard` 和 `lite` 两种资源模式。
2. 删除 Makefile 中的 `start` 目标，不再提供 `make start` 等别名。
3. Makefile 只保留检查、测试、构建、迁移和诊断等维护命令。
4. 保留首次安装与专项工具脚本；它们不得再包装出新的日常启动入口。
5. README、新手指南和开发指南统一展示 `./start.sh`，减少跨机器部署和故障排查时的歧义。

## 结果

- 用户只需记住一个启动命令，文档、排障和实际执行路径完全一致。
- 首次部署与日常启动仍然分离，避免把依赖安装和大模型下载重新塞入每次启动流程。
- 删除 Makefile 别名会使旧的 `make start` 命令失败；迁移方式是直接执行 `./start.sh`。
