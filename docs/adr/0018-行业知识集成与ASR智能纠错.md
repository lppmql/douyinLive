# ADR 0018：行业知识集成与 ASR 智能纠错双通道

**日期**：2026-07-25  
**状态**：已采纳  
**决策者**：lppmql

---

## 背景

项目有两条知识管线：
1. **直播复盘知识**（已有）：直播话术、评论、指标、AI 分析 → MySQL + Qdrant
2. **行业静态知识**（缺失）：品牌红黑榜、区域分布、行业术语

行业知识对业务至关重要——它既是 AI 问答的「标准答案」，也是 ASR 语音识别的「领域词典」。

同时，FunASR 对零食店行业的专有名词（品牌名、术语）识别准确率偏低，经常把「好想来」识别成「好想赖」、「赵一鸣」识别成「赵一明」。

## 方案对比

### 行业知识入库方式

| 方案 | 优点 | 缺点 |
|------|------|------|
| A：导入现有知识库 | 复用混合搜索/问答/AI | 行业知识和直播数据混在一起 |
| B：新建独立模块 | 管理清晰 | 开发量大，和问答系统割裂 |
| C：写进提示词 | 最简单 | 长度有限，用户搜不到 |

**选择方案 A**：管道已铺好（`knowledge_base` 表 + Qdrant 向量 + 混合搜索 + AI 问答），只需灌数据。

### ASR 纠错方式

| 方案 | 优点 | 缺点 |
|------|------|------|
| FunASR hotwords（事前） | 原生支持，零成本 | 只能加权，不能强制纠错 |
| 后处理纠错（事后） | 精确校正 | 可能误改正常文本 |
| 两者结合 | 互补 | 实现稍复杂 |

**选择两者结合**：hotwords 让 FunASR 优先识别品牌名，后处理把漏网之鱼校正。

## 技术细节

### 行业知识导入

- **源数据**：`docs/行业知识/零食店红黑榜.md` + `docs/行业知识/零食店品牌区域分布.md`
- **拆分策略**：红黑榜拆为 7 条（4 个头部品牌详情 + 黑榜 + 二线推荐 + 通用要求），区域分布按省份拆为约 34 条
- **存储**：MySQL `knowledge_base` 表（`source_type="manual"`, `category="行业知识"`）+ Qdrant `douyin_live_knowledge` 集合
- **幂等性**：同 title 条目自动更新，不重复插入
- **触发时机**：FastAPI 启动时自动执行

### FunASR hotwords

- **提取来源**：从行业知识 Markdown 自动提取品牌名、术语、地名
- **数量**：约 145 个（FunASR 建议不超过 200）
- **格式**：空格分隔字符串，如 `"好想来 赵一鸣 零食很忙 快招公司 ..."`
- **注入位置**：`funasr_client.py` WebSocket 握手消息的 `hotwords` 字段

### 后处理纠错器

- **算法**：编辑距离（Levenshtein distance）模糊匹配
- **阈值**：统一为 1（只纠错单字差异的 ASR 错误）
- **词典**：141 个精准品牌名 + 核心术语（手动维护，不自动提取以避免噪声）
- **安全机制**：
  - 已正确识别的词典词条区域受保护，不纠错
  - 窗口内任意位置被保护即跳过（防止跨词边界替换）
  - 非汉字字符不参与纠错

## 影响范围

### 新增文件
- `backend/app/services/asr/hotwords.py` — 热词提取器（~220 行）
- `backend/app/services/asr/corrector.py` — ASR 后处理纠错器（~280 行）
- `backend/scripts/import_industry_knowledge.py` — 行业知识导入脚本（~170 行）
- `backend/tests/test_asr_corrector.py` — 纠错器单元测试（12 个用例）
- `docs/行业知识/` — 行业知识 Markdown 文档

### 修改文件
- `backend/app/services/asr/funasr_client.py` — `hotwords=""` → `hotwords=get_hotwords_cached()`
- `backend/app/main.py` — startup 事件中调用 `import_industry_knowledge()`
- `backend/workers/asr_worker.py` — `_consume_transcription` 中调用 `correct_text()`
- `start.sh` — Qdrant 健康检查路径修正

## 后续考虑

- 行业知识更新：重新运行 `python -m scripts.import_industry_knowledge` 或重启后端
- 纠错词典扩展：在 `hotwords.py` 的 `build_correction_dictionary()` 中添加新品牌名
- FunASR hotwords 效果评估：对比开启/关闭 hotwords 时的品牌名识别准确率
