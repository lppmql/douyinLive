# ADR 0039：AI 剪辑多信号选段与精确字幕版本化

- 日期：2026-08-08
- 状态：已采纳
- 关联：ADR 0038（替代其中“均匀抽样、字符比例字幕、直接烧录分片”的实现）

## 背景

第一版 AI 自动剪辑已经能从回放生成 5 条成片，但有两个直接影响可用性的问题：

1. 选段主要依赖话术和均匀抽样，评论爆发、钩子、互动增长、确认客资等真实转化
   信号没有参与候选排序；
2. FunASR 已返回 token 时间戳，但系统只保存整句起止时间，成片字幕继续按字符比例
   分时。遇到停顿、纠错和多段拼接时会出现提前、滞后或跨片段漂移。

## 备选方案

### 方案 A：并行引入 Whisper/第三方剪辑框架

优点是现成项目通常自带字幕和审阅界面；缺点是会形成第二套 ASR、模型下载、任务
状态和素材目录，8GB 本机的资源占用与维护成本明显增加，也无法直接复用项目已有的
评论、钩子和确认客资口径。

### 方案 B：在现有模块化单体中补齐多信号与精确时间（采纳）

保留 FunASR、DeepSeek、ffmpeg 和现有持久任务队列。新转写直接保存逐字/词时间；
历史场次只对最终入选的 30-90 秒候选做二次离线对齐。评论、指标、钩子和客资先由
确定性规则生成可解释分数，再由 LLM 在真实话术行号中做内容决策。

## 最终决策

1. `transcript_segments` 保存纠错前原文、纠错后逐字/词时间以及时间来源。行业词纠错
   通过文本差异映射回原音频窗口，不因文字长度变化而推移后续字幕。
2. 历史片段没有逐字时间时，剪辑任务从本地真实回放抽取候选 PCM，并调用现有
   FunASR `offline` 协议做二次对齐；单段失败明确降级为 `segment_estimated`，不伪造
   精确结果。
3. 多信号分只使用真实数据库事实：附近评论、高意向评论、累计指标差、正式钩子、
   已归属确认客资和已有话术评分。“片段后 5 分钟客资”单独展示；只有片段同时覆盖
   正式钩子时才作为弱排序信号，并始终标注“时间窗关联，不代表确定因果”。
4. 超长话术输入改为“高信号候选优先 + 全场均匀覆盖”，LLM 仍只能输出输入行号，
   不能自编时间戳。
5. 渲染管线改为“竖屏片段 → 无字幕 clean.mp4 → 拼接 → 全片一次烧录字幕”。
   每次渲染写入 `clips/<clip_id>/v<version>/`，旧文件不覆盖；字幕修订只复用底片重跑
   烧录步骤。字幕任务保存目标版本，崩溃恢复时不会重复生成更高版本；每条成片保留
   最近 20 个历史版本引用，超限版本在数据库提交成功后按安全根路径清理；渲染失败
   且尚未被数据库引用的版本目录立即删除。
6. 同时输出 ASS 和 SRT。审阅页显示字幕精度、版本、真实选段证据，支持逐段改字和
   “仅重制字幕”；`funasr_aligned`（token 比例时间对齐）与 `funasr_remapped`（文字
   纠错重映射）独立展示。旧成片没有 clean.mp4 时要求先重剪一次。
7. 整场重新生成不再删除旧数据库记录，而是标为 `discarded`，避免媒体文件失去唯一
   引用；每场只保留最近 10 条可安全识别为独占目录的已丢弃记录，超限记录及媒体
   一并清理，页面数据和磁盘占用有明确上限。同场次已有任务时字幕提交返回 409，
   前端保留用户草稿等待重试。

## 数据与接口影响

- `transcript_segments` 新增 `raw_text_content`、`word_timestamps_json`、
  `timestamp_source`。
- `clip_clips` 新增主题、无字幕底片、SRT、字幕精度、渲染版本、历史版本、选段证据
  和质检 JSON。
- 新增 `POST /api/v1/clip/clips/{clip_id}/subtitle/rerender` 和
  `GET /api/v1/clip/clips/{clip_id}/subtitle.srt`。
- 迁移：`b3c4d5e6f7a8_phase_43_precise_clip_subtitles.py`。

## 约束

- 不自动发布抖音，继续由运营确认后人工发布。
- 不把时间窗关联描述为客资因果。
- 不引入第二套 ASR 或新前端依赖。
- 旧话术只有在候选入选时才做精确对齐，控制本机资源和处理时长。
- 候选二次对齐在 ffmpeg 提取和 FunASR 发送/等待期间每 0.5 秒检查取消状态；取消和
  安全关机异常不得降级吞掉，无视频草稿统一标记失败以便后续重试。

## 验收方式

1. 含停顿的逐字字幕保留真实无字幕区间，多段拼接后第二段时间从成片累计时长开始。
2. 行业词纠错前后长度变化时，字幕仍落在原音频窗口内。
3. 历史话术候选触发二次对齐；FunASR 不可用时成片标记为“片段估算”。
4. 选段证据能回溯到真实评论、指标、钩子和确认客资，页面明确展示关联口径。
5. 字幕修订生成 v2，v1 文件路径保留；画面起止时间不能通过字幕接口修改。
6. 同一字幕任务恢复执行时保持目标版本不变；第 21 个历史版本产生后清理最旧文件。
