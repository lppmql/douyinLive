# douyin_live 业务数据库数据字典

> 数据库：`douyin_live`（MySQL 8.0，容器 `douyin_live_mysql`）
> 生成日期：2026-08-18
> 用途：供 DataEase 数据源配置与数据集设计参考，也可作为开发查字段手册。

## 1. 数据库概览

| 类别 | 数量 |
|------|:----:|
| 只读视图（de_v_\*，DataEase 推荐数据源） | 12 |
| 分析汇总表（de_\*） | 7 |
| 业务明细表 | 37 |
| **合计** | **56** |

## 2. DataEase 数据源连接速查

在 DataEase 后台新增数据源（类型 MySQL）时填写：

| 表单字段 | 填写值 |
|---------|--------|
| 主机 / 地址 | `mysql`（容器名，不要填 localhost） |
| 端口 | `3306` |
| 数据库 | `douyin_live` |
| 用户名 | `dataease_reader` |
| 密码 | `DataEase@root123` |
| 编码 | `utf8mb4` |

> 该账号只有 `SELECT`、`SHOW VIEW` 只读权限，可安全用于 DataEase 数据源。

## 5. DataEase 数据集使用建议

起步建议在 DataEase 中优先建立以下 3 个数据集，即可覆盖核心看板：

| 数据集名 | 用哪个数据对象 | 能做的分析 |
|---------|--------------|-----------|
| 场次经营明细 | 视图 `de_v_fact_live_session` | 每场直播观看→涨粉→留资→广告费 ROI 趋势 |
| 主播汇总 | 汇总表 `de_live_session_anchor_summary` | 主播对比、留资效果、广告投放效率 |
| 评论分析 | 视图 `de_v_fact_comment` | 高意向评论筛选、情感分析、关键词 |

更多数据集可按需从「4.1 只读视图」中扩展。
